# 字体安装说明

公文 skill 生成 GB/T 9704 公文，模板默认使用 **方正小标宋简体 / 黑体 / 楷体 / 仿宋**。
这些字体若本机缺失，`generate.py` 会在生成前**自动检测并降级**到已装的等效字体（详见下方），
因此**不装任何字体也能生成可读公文**。但若追求严格符合国标的视觉效果，请按下文准备字体。

---

## 一、字体用途对照

| 字体 | 用途 | 是否必需 |
|------|------|---------|
| **方正小标宋简体** | 文件标题、红头发文机关 | ⚠️ 商业字体，多数电脑无 |
| **黑体**（黑体-简 / SimHei） | 一级标题、红头副标题 | ✅ macOS/Windows 通常自带 |
| **楷体**（楷体-简 / KaiTi） | 二级标题 | ✅ macOS/Windows 通常自带 |
| **仿宋**（FangSong） | 正文、发文字号 | ✅ macOS/Windows 通常自带 |

> 只有「方正小标宋」是需要额外准备的，其余三种系统基本自带。

---

## 二、方正小标宋简体（商业字体，合法获取）

方正小标宋简体是**北大方正**的商业字体，**不可打包随 skill 分发**。合法获取渠道：

1. **单位授权**：多数党政机关、国企有方正字体的单位授权，向本单位信息/文印部门索取安装包。
2. **方正官方购买**：https://www.foundertype.com （个人/企业授权）。
3. **已有授权的电脑拷贝**：从已获授权的电脑复制字体文件安装（仅限授权范围内）。

> ⚠️ 请勿从非授权渠道下载。商业字体未授权使用有法律风险。

---

## 三、开源替代方案（推荐，免费可商用）

若无法获取方正小标宋，推荐使用 **思源字体（Source Han / 思源黑体 / 思源宋体）**：
Adobe + Google 联合开发，**SIL Open Font License 1.1 协议，免费可商用**。

| 国标字体 | 思源替代 | 下载 |
|---------|---------|------|
| 方正小标宋（标题） | 思源宋体 **Heavy** 字重 | [GitHub releases](https://github.com/adobe-fonts/source-han-serif/releases) |
| 黑体 | 思源黑体 | [GitHub releases](https://github.com/adobe-fonts/source-han-sans/releases) |
| 仿宋 / 楷体 | 思源宋体（无完美开源替代） | 同上 |

skill 已附带 `references/official_document_compat.yaml` 预设，直接用思源字体，无需方正字体：

```bash
python3 scripts/generate.py content.json out.docx --template official_document_compat
```

## 四、安装方法

### macOS
1. 双击 `.ttf` / `.otf` 字体文件，弹出"字体册"预览，点【安装字体】；
2. 或直接把字体文件拷到 `~/Library/Fonts/`（当前用户）或 `/Library/Fonts/`（所有用户）。

### Windows
1. 右键字体文件 → 【为所有用户安装】（需管理员）或【安装】（当前用户）；
2. 或拷到 `C:\Windows\Fonts\`（所有用户）或 `%LOCALAPPDATA%\Microsoft\Windows\Fonts\`（当前用户）。

### Linux
拷到 `~/.fonts/` 或 `~/.local/share/fonts/`，然后执行 `fc-cache -fv` 刷新字体缓存。

---

## 五、安装后验证

装好字体后，重新运行生成命令，观察输出的「🔍 字体检测」报告：

```
🔍 字体检测:
  ✓ 方正小标宋简体          ← 已安装则显示 ✓
  ✗ 方正小标宋简体 → 已降级为 "Songti SC"   ← 未安装则显示降级结果
```

全为 ✓ 即代表字体就绪，生成的公文将严格符合国标视觉。
