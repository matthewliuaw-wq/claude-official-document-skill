# 公文 Markdown 写作规范

> 本规范定义了公文 Markdown 的写作约定。遵循本规范撰写的 Markdown 文件，可通过 Claude Code Skill 自动转换为符合 GB/T 9704 标准的 Word 公文文档。

---

## 一、文件结构总览

```
---
title: 关于开展XXX的通知
org: ××××××
doc_no: ×〔2026〕×号
type: 通知
---

# 关于开展XXX的通知

各有关单位：

（正文段落）

## 一、XXXX

### （一）XXXX

1.XXXX
（1）XXXX

## 附件

1.XXXX
2.XXXX

（发文机关名称）
2026年6月5日

---

## 附件1：XXXX

（附件正文）

---

## 附件2：XXXX

（附件正文或表格）
```

---

## 二、YAML 前置信息（封面元数据）

文件开头用 YAML 块提供封面信息，用 `---` 包裹：

```yaml
---
title: 关于开展AI融合课程建设工作的通知
org: ××××××
doc_no: ×〔2026〕×号
type: 通知
---
```

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `title` | ✅ | 文件标题（不含"关于"前的修饰语，完整标题） | `关于开展AI融合课程建设工作的通知` |
| `org` | ✅ | 发文机关名称 | `北京大学教育学院` 或 `××××××` |
| `doc_no` | ✅ | 发文字号 | `教研〔2026〕12号` 或 `×〔2026〕×号` |
| `type` | ✅ | 公文类型 | `通知` / `请示` / `报告` / `函` |

> **说明**：如果不提供 YAML 块，Skill 将使用占位符生成，用户可在 Word 中手动修改。

## 三、正文各元素写法

### 3.1 文件标题

用**一级标题** `#`，居中显示，一般格式为"关于……的通知/请示/报告/函"。

```markdown
# 关于开展AI融合课程建设工作的通知
```

**注意**：标题独占一行，前后不加任何修饰。

### 3.2 主送机关

紧跟标题之后，**独立一行**，以**全角冒号** `：` 结尾。

```markdown
各院系、各部门：
```

```markdown
市教育局：
```

```markdown
××××××：
```

**识别规则**：正文开头第一个以 `：` 结尾的独立段落。

### 3.3 正文段落

普通文本段落，不需要任何 Markdown 标记。每段首行缩进 2 字符（Word 自动处理）。

```markdown
为深入贯彻落实国家关于推进人工智能与教育教学深度融合的战略部署，加快推进我校AI融合课程建设工作，现就有关事项通知如下。
```

**注意**：
- 段落之间用**空行**分隔
- 不要在段落前加缩进空格（Word 会自动缩进）

### 3.4 第一层标题（黑体）

用**二级标题** `##`，手写编号 `一、` `二、` `三、`。

```markdown
## 一、总体目标

## 二、主要任务

## 三、工作要求
```

**注意**：
- 编号手写，不用 Markdown 自动编号
- 编号后用**顿号** `、`，不用逗号或句号
- `##` 和编号之间有**一个空格**

### 3.5 第二层标题（楷体）

用**三级标题** `###`，用**中文括号** `（一）` `（二）` `（三）`。

```markdown
### （一）课程设计

### （二）资源开发

### （三）教师培训
```

**注意**：
- 用中文括号 `（）`，不用英文括号 `()`
- 括号内用中文数字，不用阿拉伯数字

### 3.6 第三层（仿宋）

用**普通段落**，以**阿拉伯数字+半角句点** `1.` `2.` `3.` 开头。

```markdown
1.通识课程应在现有教学内容中融入AI伦理、AI工具使用等基础模块。

2.专业课程应结合专业特色，设计AI辅助实验、AI数据分析等实践环节。
```

**注意**：数字后用**半角句点** `.`，不用顿号。

### 3.7 第四层（仿宋）

用**普通段落**，以**中文括号+阿拉伯数字** `（1）` `（2）` `（3）` 开头。

```markdown
（1）理工类课程重点融入机器学习、深度学习等技术的应用案例。

（2）人文社科类课程重点融入大语言模型在文本分析中的应用。
```

## 四、结尾元素

### 4.1 结尾用语（可选）

根据公文类型，正文最后可加结尾用语：

| 公文类型 | 结尾用语 |
|---------|---------|
| 通知 | 特此通知。 |
| 请示 | 妥否，请批示。 |
| 报告 | 特此报告。 |
| 函 | 请予函复。/ 特此函达。 |

```markdown
特此通知。
```

### 4.2 附件标注

用 `## 附件` 作为二级标题，附件列表用阿拉伯数字编号。

```markdown
## 附件

1.AI融合课程建设指南

2.AI融合课程建设经费申请表
```

**注意**：
- 单个附件写 `附件：XXX`（不用编号）
- 多个附件分别写 `1.XXX` `2.XXX`（编号后无空格，用半角句点）
- 附件名称后**不加标点符号**

### 4.3 落款

落款和日期各**独占一行**，不加任何 Markdown 标记。

```markdown
（发文机关名称）

2026年6月5日
```

**注意**：
- 落款和日期之间可以有空行，也可以没有
- 日期格式为 `YYYY年M月D日`，月份和日期不补零
- Word 中自动右对齐

## 五、附件页

### 5.1 分页符

用 `---`（三个短横线）分隔主文和附件。

```markdown
（主文结束）

---

## 附件1：AI融合课程建设指南
```

### 5.2 附件页标题

用**二级标题** `##`，格式为 `附件N：附件标题`。

```markdown
## 附件1：AI融合课程建设指南
```

**注意**：
- 编号用阿拉伯数字
- 编号后用**全角冒号** `：`
- 附件页标题自动居中显示

### 5.3 附件正文

附件正文结构与主文相同，可包含所有层级：

```markdown
## 附件1：AI融合课程建设指南

## 一、建设目标

通过AI融合课程建设，实现教学内容现代化。

## 二、建设内容

### （一）课程设计

结合学科特点，设计AI融合课程教学大纲。

1.通识课程应融入AI伦理等基础模块。

（1）理工类课程重点融入机器学习案例。

### （二）资源开发

1.智能课件：利用AI工具生成个性化课件。
```

### 5.4 申请表（附件中的表格）

用 Markdown 表格语法：

```markdown
## 附件2：AI融合课程建设经费申请表

| 项目 | 内容 |
|------|------|
| 课程名称 | |
| 所属单位 | |

| 课程类型 | □通识课程  □专业课程  □实验课程 |
| 预计建设周期 | □6个月  □12个月  □18个月 |
| 申请经费（万元） | |
| 课程现状简介 | |
| AI融合改造方案 | |
| 预期成果 | |

| 专家评审意见 | |

填表人签字：　　　　　　日期：

```

**注意**：
- 表格用标准 Markdown 语法（`|` 分隔，第二行用 `---`）
- 空单元格直接留空（`| |`）
- 勾选项用 `□`（全角方框）
- 签字行写在表格下方，用全角空格 `　` 对齐

## 六、层级速查表

| 层级 | Markdown 写法 | 显示字体 | 示例 |
|------|-------------|---------|------|
| 文件标题 | `# 标题` | 方正小标宋 二号 | `# 关于开展XXX的通知` |
| 第一层 | `## 一、XXX` | 黑体 三号 | `## 一、总体目标` |
| 第二层 | `### （一）XXX` | 楷体 三号 | `### （一）课程设计` |
| 第三层 | `1.XXX`（普通段落） | 仿宋 三号 | `1.通识课程应融入AI伦理。` |
| 第四层 | `（1）XXX`（普通段落） | 仿宋 三号 | `（1）理工类课程重点融入……` |

## 七、完整示例

```markdown

type: 通知
---

# 关于开展AI融合课程建设工作的通知

各有关单位：

为深入贯彻落实国家关于推进人工智能与教育教学深度融合的战略部署，加快推进AI融合课程建设工作，现就有关事项通知如下。

## 一、总体目标

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的教育方针，落实立德树人根本任务，以人工智能技术赋能教育教学改革。

## 二、主要任务

### （一）课程内容改造

各有关单位应结合学科特点，将人工智能相关知识、工具和方法有机融入现有课程体系。

1.通识课程应在现有教学内容中融入AI伦理、AI工具使用等基础模块。

2.专业课程应结合专业特色，设计AI辅助实验、AI数据分析等实践环节。

（1）理工类课程重点融入机器学习等技术的应用案例。

（2）人文社科类课程重点融入大语言模型在文本分析中的应用。

### （二）教学方法创新

鼓励教师探索基于AI的混合式教学、个性化学习、智能辅导等新型教学模式。

### （三）教学资源建设

建设AI融合课程资源库，包括智能课件、虚拟实验、在线测评等数字化教学资源。

## 三、工作要求

### （一）加强组织领导

各有关单位要成立AI融合课程建设工作组，明确责任分工。

### （二）确保建设质量

课程改造应坚持质量导向，注重实效，避免形式主义。

### （三）按时完成建设

各有关单位应于2026年9月前完成首批AI融合课程的建设工作。
```

## 八、四种公文类型的差异

| 差异点 | 通知 | 请示 | 报告 | 函 |
|--------|------|------|------|-----|
| 标题后缀 | …的**通知** | …的**请示** | …的**报告** | …的**函** |
| 主送机关 | 下级（多个） | 上级（单个） | 上级（单个） | 平级（单个） |
| 结尾用语 | 特此通知。 | 妥否，请批示。 | 特此报告。 | 特此函达。 |
| 附件 | 常有 | 常有 | 偶有 | 少有 |
| type 值 | `通知` | `请示` | `报告` | `函` |

除以上差异外，四种公文的 Markdown 写法完全相同。
